## Work together

The **Team** view shows who is working right now, on which task and branch.

If a teammate is editing the same file as you, you both get a heads-up before it turns into a merge conflict.

**Huddle** invites people to a call. **Pair** starts a Live Share session so you can code together.

Choose what others see with the `bldt.presence.share` setting, or go invisible from the Team view.
